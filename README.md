# ecs163-final-project
## Description
This repository has metadata and supplemental files such as this README.md file in the root of the directory. The actual app logic and data is contained within the `\app` folder. Within `\app`, there is our main entry point `index.html`, which referes to other files such as `index.css` and `main.js`. To create easy workload distribution, the seperate visualizations are split into multiple files within the `components` folder. The data is kept in the `data` folder. There is also global state information that is passed around through the `appState.js` file.

## Installation
In order to run this visualization, you will need to have a working modern web browser and a way to set up a server on the `index.html` file either with Python or the VSCode extension - Live Server.

## Execution
To run the code, simply start a server with the following file: `/app/index.html`. If using the VSCode extension, the browser window may automatically pop up with the visualzation. Make sure to run this through the `app` directory so that you can use the `index.html` file. You may need to navigate to `http://127.0.0.1:5501/app/`.
